# Redeploy Proof Loop

1. Obtain a fresh checkout of the repository containing this source.
2. Confirm Python 3.10 or newer is available.
3. Run the quick-start commands in the README.
4. Review templates/codex/AGENTS.md and the intake skill before copying them into a project.
5. Keep acceptance pins outside the author's writable project and under separate reviewer/operator custody.
6. Invoke the local CLI explicitly. Do not treat instructions as a sandbox or install global hooks without a separate review.

A successful local installation does not prove host activation, independent acceptance-pin custody, or production readiness.
