# Synthetic scenarios

All examples here are invented. They contain no user project material or historical operational evidence.

| Task | Evidence to supply | Limit |
| --- | --- | --- |
| Compare a JSON record list with a count and ordered-ID view | Declared source/view files and a frozen contract; run the built-in drift check | Proves only the implemented projection comparison |
| Repair a small arithmetic function | Your source, protected requirements and test command | Optional agent bridge completion is advisory; arbitrary test output has no portable acceptance adapter |
| Review a written claim | Your claim, permitted source excerpts and a source map | Instructions guide review; the CLI does not establish factual truth |

Start with the disposable smoke in `tools/clean_start_smoke.py`. The synthetic JSON and agent-bridge examples demonstrate separate paths; no example is a real customer project or production qualification.
